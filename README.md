# مساعد المبيعات اللحظي (نسخة مستقلة)

## اللي محتاجه (مرة واحدة)
1. **مفتاح API:** ادخل console.anthropic.com، اعمل حساب، ضيف رصيد صغير (مثلًا 5 دولار)، وأنشئ API Key وانسخه.
2. **حساب GitHub** (مجاني) و**حساب Render** (render.com، فيه خطة مجانية).

## الرفع (حوالي 10 دقايق)
1. على GitHub اعمل مستودع جديد (Private) وارفع كل ملفات المجلد ده.
2. في Render: New ← Web Service ← اختار المستودع.
   - Build Command: (سيبه فاضي)
   - Start Command: `node server.js`
3. من Environment Variables ضيف:
   - `ANTHROPIC_API_KEY` = مفتاحك
   - `APP_PASSWORD` = كلمة سر من اختيارك (**مهم**، عشان محدش يستخدم مفتاحك)
4. بعد ما يخلص هيديك رابط https. افتحه، وفي ⚙️ الإعدادات اكتب كلمة السر ومعلومات شركتك.

## التثبيت كتطبيق
- **آيفون (Safari):** مشاركة ← إضافة إلى الشاشة الرئيسية.
- **أندرويد (كروم):** القايمة ← تثبيت التطبيق.

## ملاحظات
- التكلفة بتتحسب من رصيد الـ API عندك، منفصلة عن حدود كلود اليومية. تابعها من console.anthropic.com.
- الخطة المجانية في Render بتنام بعد فترة، فأول فتح ممكن ياخد 30-50 ثانية. افتحه قبل المكالمة بشوية.
- الاستماع بيستخدم خدمة المتصفح (على الآيفون ممكن يقف ويشتغل تاني). لو محتاج استماع أقوى نضيف خدمة تفريغ صوت.
- خد موافقة الشركة قبل ما تستخدمه مع عملاء حقيقيين، وماتكتبش أسماء العملاء.
